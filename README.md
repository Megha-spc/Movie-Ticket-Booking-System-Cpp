# 🎬 Movie Ticket Booking System (C++)

## 📌 Project Description
This is a simple console-based Movie Ticket Booking System developed using C++ and Object-Oriented Programming (OOP) concepts.

## ✨ Features
- Book Movie Ticket
- View Booking Details
- Cancel Ticket
- Exit Program

## 🛠 Technologies Used
- C++
- Object-Oriented Programming (OOP)

## 📚 OOP Concepts Used
- Class & Object
- Constructor
- Encapsulation
- Member Functions

## 🚀 How to Run
1. Open the project in any C++ IDE.
2. Compile the code.
3. Run the program.
4. Use the menu options.
